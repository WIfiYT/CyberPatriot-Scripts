Sudo rm (filepath): deletes with administrator privilidges. requires admin.
rm (filepath): deletes file/folder.
sudo ufw enable: enables the firewall. requires admin.
sudo ufw status: checks status of firewall. requires admin.
cat (filepath): shows code of specific file.
ls (filepath): shows directory and other folders and files.
sudo chmod (###) (filepath): chenges permissions for file. requires admin.
sudo apt update: updates system for Ubuntu/Debian. required admin.
sudo apt upgrade: updates large system stuff. requires admin.
sudo deluser: deletes user. requires admin.
