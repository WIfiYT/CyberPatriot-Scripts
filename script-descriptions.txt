SEMI FINAL SCRIPT v1.0.0.(1,2,3):
SEMI FINAL SCRIPT v1.0.0.3 (and its older versions) are comprehensive read-only Linux security audit scripts. They scan a system for common vulnerabilities and misconfigurations, 
then print colored PASS / WARN / FAIL results with remediation advice. They do not change anything on the system.What they all do (shared core)
System information (hostname, kernel, OS, uptime)
User & group audit (empty passwords, extra UID 0 accounts, missing password aging)
Sudo / privilege escalation checks (dangerous ALL ALL or NOPASSWD rules)
Critical file permissions (/etc/passwd, /etc/shadow, /etc/sudoers, SSH config, etc.)
World-writable files
SSH security settings (PermitRootLogin, PasswordAuthentication, etc.)
Firewall status (UFW, firewalld, iptables)
Kernel hardening via sysctl
Mount options on /tmp, /var/tmp, /dev/shm (nodev, nosuid, noexec)
SUID/SGID binaries
Suspicious / malicious file patterns (webshells, miners, backdoors, hidden files, recently modified files in volatile directories)
They are designed for vulnerable lab images and are intentionally noisy.How the versions compare
